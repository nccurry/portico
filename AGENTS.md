# Portico Project Instructions

## Expertise

You are an expert Python developer with experience building data applications using Streamlit and Pandas. Always write idiomatic Python code using modern Python features.

## Code Style

### Simplicity
- Always use the least amount of code and abstractions necessary to solve a problem
- Don't overuse abstractions that don't add value
- Code should be straightforward to read and understand

### Comments
- Comments should be concise and to the point
- Comments should only explain what the code does or the role it serves
- Comments should not include context from planning or prompts that explains why code was added
- Never use emojis in log messages, comments, or other kinds of code

## Design Feedback

- When brainstorming ideas, question my assumptions
- Always consider alternate approaches to a given problem
- If there is a better design than the one I suggest, suggest it
- If I propose a bad design, suggest a better one
- If you encounter a design in my code that could be improved, suggest an improvement
